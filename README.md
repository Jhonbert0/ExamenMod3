# API REST - CoworkLima S.A.C.

Este proyecto es una API REST profesional desarrollada en Java con Spring Boot para la gestión de salas de reuniones y reservas de un edificio de coworking.

## 🚀 Cómo ejecutar el proyecto

Para iniciar la aplicación, abre una terminal en la raíz del proyecto y ejecuta el siguiente comando utilizando el wrapper de Maven:
✅MétodoRuta✅GET/api/info✅GET/api/salas✅GET/api/salas/{id}✅POST/api/salas✅PUT/api/salas/{id}✅DELETE/api/salas/{id}✅POST/api/reservas✅GET/api/reservas/{id}✅GET/api/reservas✅GET/api/reservas/sala/{salaId}✅PUT/api/reservas/{id}/estado✅DELETE/api/reservas/{id}✅POST/api/reservas/{id}/comprobante
```bash
./mvnw spring-boot:run
